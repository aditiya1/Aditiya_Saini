# Aditiya Saini - Portfolio Website

An interactive and modern portfolio website built with React, showcasing my skills, experience, education, and projects.

## Features

- 🎨 **Modern UI/UX Design** - Beautiful, responsive design with smooth animations
- ⚡ **Interactive Components** - Engaging user experience with Framer Motion animations
- 📱 **Fully Responsive** - Works seamlessly on all devices
- 🎯 **Smooth Navigation** - Fixed navbar with active section highlighting
- 💼 **Professional Sections**:
  - Hero section with animated introduction
  - About me section
  - Experience timeline
  - Education details
  - Technical skills with progress bars
  - Certifications showcase
  - Contact form with social links

## Technologies Used

- **React** - UI library
- **Framer Motion** - Animation library
- **HTML5 & CSS3** - Structure and styling
- **JavaScript (ES6+)** - Interactivity

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository or navigate to the project directory:
```bash
cd Portfolio_project
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Build for Production

To create a production build:

```bash
npm run build
```

This builds the app for production to the `build` folder.
